HOW FAISS FINDS SIMILAR CHUNKS

Query vector: [0.019, -0.142, 0.887, …]

↓ L2 distance to every stored chunk vector

Chunk A "Accenture revenues $18B" → dist 0.34 ✅

Chunk B "Accenture bookings $22.1B" → dist 0.41 ✅

Chunk C "Gold is safe-haven asset" → dist 0.87 ❌

Threshold 0.65: keeps relevant, drops noise

WHY HYBRID SEARCH?

Semantic finds meaning even with different words

"revenue" matches "earnings" — no exact word needed

BM25 Keyword catches exact terms semantic misses

Ticker symbols, names, figures like "$18.0B"

RRF: docs scoring well in both lists rank highest

③ Production platform layers
04

The system around
the RAG core.

LLM GATEWAY
One entry point: auth → policy → quota → cache → complexity routing. Small model for simple asks, escalate to large on demand. Tracks TTFT/TPS & per-team cost.
AUTHENTICATION
API key → team + roles, keys stored hashed. Identity is fixed server-side and feeds quotas + RAG access control.
AGENT MEMORY
Four layers — working · long-term · shared · episodic — with staleness flags, validation before use, and forgetting.
RESILIENCE
Classify transient vs permanent → retry with backoff · resumable checkpoints · fallback → human handoff. Resume at step 8, not step 1.
INFERENCE SCALING
Dynamic micro-batching keeps the model busy · bounded replica pool · backpressure sheds load instead of queuing unbounded. The throughput ↔ latency trade-off, measured.

AI & Data Services
Groq API
  • openai/gpt-oss-120b — primary chat LLM
  • Supervisor, writer, reflect, guard nodes
  • run_evals.py judge (LLM-as-judge)
  • Free tier: 200,000 TPD
  • Fallback: llama / qwen / kimi models
Google Gemini API
  • gemini-embedding-001 — FAISS embeddings
  • models/gemini-embedding-001 (1536-dim)
  • gemini-3.6-flash — rag_eval.py judge
  • gemini-3.5-flash-lite — RAGAS judge
  • Free tier: 20 req/day per model
Tavily Search API
  • mcp_search_the_web tool
  • Async live web search
  • Used by web-specialist node
  • News, market data, current events
FAISS Vector Store
  • faiss_index/ — local disk, L2 distance
  • 67 chunks (PDFs + manual KB)
  • Threshold: 0.65 (relevant < 0.49)
  • Provenance: source · doc_version · ingested_at
  • STALE flag after 90 days
  • Rebuilt by ingest.py on data change
SQLite (memory.db)
  • LangGraph checkpointer — full chat history
  • trade_history — executed positions
  • signals — scanner pass records
  • scan_rejects — rejected with reason
  • forward_returns — 10-session returns
  • paper_positions — paper book
  • eval_findings — loop findings log

Evaluation & Operations
run_evals.py
  • Groq judge (LLM-as-judge)
  • 20 cases, all categories
  • Faithfulness + Relevance (1–5)
  • Tool-match check per case
  • evals/results/run_*.json
run_ragas.py
  • RAGAS library + Gemini judge
  • 8 retrieval + faithfulness_trap cases
  • Faithfulness / Context Recall (0–1)
  • Reads /chat/debug_state for contexts
  • --rescore to re-judge saved answers
rag_eval.py
  • Manual metrics (no RAGAS dependency)
  • Precision@K · Recall@K · MRR · Hit Rate
  • Faithfulness · Answer Relevancy
  • Context Precision · Context Recall
  • logs/rag_eval_*.json
eval.py (Trading)
  • Observe → Eval → Plan → Act loop
  • Forward returns vs scanner edge
  • Auto-tightens thresholds (rules.py)
  • Gate: MIN_OBS_EDGE=120 before acting
  • eval_findings table in SQLite
Scheduler & Broker
  • APScheduler: 09:15 IST Mon–Fri
  • scanner.py → top picks → proposal
  • Telegram HITL: approve/reject
  • ICICI Breeze API on approval
  • swing_routes.py read endpoints
Observability Outputs
  • logs/metrics.jsonl — per request JSONL
  • logs/token_usage_DATE.json — daily totals
  • logs/provider_caps.json — learned 429 caps
  • Warns at 80% of daily budget
  • Per-node token breakdown in console
Private networking: all services on localhost  |  No public endpoints  |  LangGraph Studio compatible (studio_graph.py)  |  Resource: local Windows 11 dev machine

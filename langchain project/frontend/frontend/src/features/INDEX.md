## 💬 Interview Day Scripts

### When they ask about Event Loop:

"The JavaScript runtime has 5 key components:

1. Call Stack - where code executes
2. Web APIs - browser handles timers, fetch, etc
3. Microtask Queue - Promises (HIGH priority)
4. Macrotask Queue - setTimeout, I/O
5. Event Loop - continuously orchestrates

When the Call Stack empties, ALL Microtasks execute first,
then ONE Macrotask, then repeat. This is why Promises
execute before setTimeout."

### When they ask about debounce:

"Debounce delays execution until after a period of inactivity.
The key is clearing the previous timeout on each call.
Use case: search inputs to avoid API spam. Without clearing,
the function would execute at every keystroke."

### When they ask to optimize:

"First, I measure to identify the bottleneck using React DevTools
or Chrome DevTools. Then I apply targeted optimizations like
React.memo for unnecessary re-renders, useCallback for
function references, or useMemo for expensive computations.
Never optimize without measuring first."
